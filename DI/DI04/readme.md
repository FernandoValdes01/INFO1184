# DI04 - Presentacion TA04

Presentacion de apoyo para la disertacion 04 de INFO1184, basada en la resolucion de `TA/TA04` sobre PCA aplicado al dataset `Boston`.

## Archivo principal

- `DI_4_INFO1184_Juan_Munoz.pptx`: presentacion minimalista y profesional con problema, metodologia CRISP-DM, PCA, respuestas y conclusiones.

## Regenerar presentacion

Desde esta carpeta ejecutar:

```bash
python3 generar_presentacion_di04.py
```

El script convierte figuras de `TA/TA04/figuras` a PNG dentro de `assets_di04/` y reconstruye el archivo `.pptx`.
